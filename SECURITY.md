# Security policy

## Report a vulnerability privately

Please do not disclose vulnerabilities, pairing codes, API keys, browser
content, or session ledgers in public issues or pull requests.

Email **[security@beanos.ai](mailto:security@beanos.ai)** to report a
vulnerability privately.

Include the affected version or commit, a minimal reproduction using synthetic
data, the expected and observed behavior, and the potential impact. Do not send
live credentials or a working pairing code. Coordinate disclosure with the
maintainers so they have an opportunity to investigate and publish a fix.

## Scope and updates

Reports concerning the extension, protocol, server, client library, CLI, and
MCP server belong here. Deployment-specific access or configuration problems
should also be reported privately to that server's provider. There is no
published long-term support policy; use the latest reviewed release available
from your provider and include its version when reporting a problem.

Read the [security model](docs/design.md) for trust boundaries, code custody,
redaction limits, and the consequences of a stolen pairing code.
