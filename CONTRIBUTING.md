# Contributing

**Remote Tab is not accepting outside contributions yet. Contributor support is
to follow.**

The code is MIT-licensed and you are welcome to read it, fork it, and build on
it under that licence. What is not in place yet is the process around
contributions: a contribution agreement, a security-report path, a triage
rotation, and the CI budget to review submissions from outside the project.

## Please do not open a pull request

Pull requests from outside the project will be closed unread. That is not a
judgement on the change — there is currently nobody assigned to review them,
and each opened pull request consumes automated review capacity that the
project pays for per run.

## What to do instead

- **Found a bug, or have a proposal?** Open an issue. Issues are read.
- **Found a security problem?** Do **not** open an issue or a pull request.
  Report it privately to the repository owner, and please give us time to fix
  it before disclosing it anywhere.

## When this changes

This file is the signal. When contributions open, it will say so here, along
with the review process, the licence terms for contributions, and what a good
submission looks like. Until then, treat the absence of a process as
intentional rather than as an invitation.
